# 6학년 2학기 수학 · 홍지희 선생님 버전

우리 학교·학급 상황으로 다시 짠 **이야기 수업** 자료입니다. 누구나 열어 볼 수 있습니다.

교과서 차시 버전은 [`../sem2/`](../sem2/)에 있습니다.
두 버전은 개념 계단 다섯 칸, 도움 3단계, S.O.O.P. 탐구 단계가 같고 차시 순서와 소재만 다릅니다.

| 단원 | 웹앱 | 이야기 | 차시 |
|---|---|---|---|
| 1 분수의 나눗셈 | `u1-fracdiv.html` | (분수의 나눗셈 이야기, 만드는 중) |  |
| 2 소수의 나눗셈 | `u2-decdiv.html` | (소수의 나눗셈 이야기, 만드는 중) |  |

인쇄용 활동지(hwpx)는 `sheets/`에 단원마다 **기본형·도전형** 두 벌이 있습니다.
교사용 자료(전체 안내서 `6-2수학_개념계단_전체안내.md`, `Code.gs`)도 이 폴더에 있습니다.

앱의 원본은 `grade6/math/_build/units/sem2/*.st.js`입니다. 이 폴더의 단원 HTML은 직접 고치지 말고 `_build/README.md`대로 다시 만드세요.

활동지 맨 뒤 **마지막 한 장**이 교사용 정답입니다.
학생용으로 뽑을 때는 인쇄 범위에서 그 한 장만 빼면 됩니다.
