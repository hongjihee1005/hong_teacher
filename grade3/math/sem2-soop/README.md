# 3학년 2학기 수학 · 이야기 버전 (잠금 방)

교사 본인만 쓰는 자료방입니다. `index.html`을 열면 비밀번호를 묻습니다.

`d/` 안의 파일은 **AES-GCM 256으로 암호화**되어 있습니다.
비밀번호에서 PBKDF2-SHA256(600,000회)으로 키를 만들어 브라우저에서 바로 풀기 때문에,
비밀번호를 모르면 파일을 내려받아도 열리지 않습니다.

교과서 차시 버전은 잠금 없이 [`../sem2/`](../sem2/)에 있습니다.
두 버전은 개념 계단 다섯 칸, 도움 3단계, S.O.O.P. 탐구 단계가 같고 차시 순서와 소재만 다릅니다.

> 비밀번호는 여기에 적지 않습니다. 잊으면 되살릴 수 없습니다.
