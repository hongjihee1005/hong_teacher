# 3학년 2학기 사회 학습 자료

2022 개정 교육과정 초등학교 3학년 2학기 사회과 수업 자료입니다.
HTML 파일 하나에 모든 것이 들어 있어 인터넷 없이도 열립니다.

- **1단원** 사회 변화와 다양한 문화 (2~15차시)
- **2단원** 옛날과 오늘날의 생활 모습 (풍습 2~8차시 / 교통 12~19차시 / 통신 21~27차시)

## 쓰는 방법

`index.html`을 열면 전체 목록이 나옵니다. 교실에서는 전체 화면(⛶) 버튼을 누르고 쓰세요.

각 차시 자료는 **도입 → 자료 탐구 → 활동 1 → 활동 2 → 정리** 다섯 단계이고,
상단 단계 버튼으로 바로 이동할 수 있습니다. 시작 화면에서 **활동 단위**
(반 · 개별 · 짝 · 모둠 · 분단 · 번호순 · 기타)를 고를 수 있습니다.

## GitHub Pages로 올리기

1. GitHub에서 새 저장소(repository)를 만듭니다.
2. 이 폴더의 파일을 모두 올립니다.
3. Settings → Pages → Branch를 `main` / `/ (root)`로 두고 Save.
4. 몇 분 뒤 `https://<계정이름>.github.io/<저장소이름>/` 으로 열립니다.

## 검증

모든 차시의 차시명, 주요 학습 내용, 용어 정의, 확인 문제 정답을
교사용교과서·지도서의 「차시별 주요 내용 정리」·「꼭 기억해요」·「보충 문제」와
한 줄씩 대조했습니다. 각 차시의 「교사 안내」에 지도서 근거를 적어 두었습니다.

## 저작권

- 사진: 위키미디어 공용의 퍼블릭 도메인 / CC 라이선스 자료만 사용하고 화면에 출처를 표기했습니다.
- 기사·영상: 본문에 넣지 않고 자료실에서 **링크**로만 연결했습니다.
- 통계: 국가데이터처 등 공공 자료를 인용하고 기준 연도를 밝혔습니다.
