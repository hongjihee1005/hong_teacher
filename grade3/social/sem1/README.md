# 3학년 1학기 사회 학습 자료

2022 개정 교육과정 초등학교 3학년 1학기 사회과 수업 자료입니다.
HTML 파일 하나에 모든 것이 들어 있어 따로 설치할 것이 없습니다.

- **1단원** 우리가 사는 곳 (주제 1 여러 장소 2~10차시 / 주제 2 도움을 주는 장소 11~21차시)
- **2단원** 일상에서 만나는 과거 (주제 1 시간의 흐름 2~9차시 / 주제 2 과거의 모습 10~17차시 / 주제 3 지역의 달라진 생활 18~27차시)
- 각 단원 1차시(단원 도입)는 만들지 않았습니다.

## 파일

| 앞글자 | 뜻 |
|---|---|
| `u단원-l차시` | 차시별 수업 세트 (34개) |
| `t단원-주제` | 주제별 자료 모음 (5개) |
| `u단원-주제-data`, `u-photos` | 자료실 (6개) |
| `a단원-이름`, `u-methods` | 활동 자료·수업 도구 (4개) |
| `h단원-주제` | 개별 학습용 우표첩 (6개) |

## 쓰는 방법

`index.html`을 열면 전체 목록이 나옵니다. 교실에서는 전체 화면(⛶) 버튼을 누르고 쓰세요.
각 차시 자료는 **도입 → 자료 탐구 → 활동 1 → 활동 2 → 정리** 다섯 단계이고, 시작 화면에서 **활동 단위**
(반 · 개별 · 짝 · 모둠 · 분단 · 번호순 · 기타)를 고를 수 있습니다. 왼쪽 아래 **👩‍🏫 교사 안내**에
성취 기준·성취 수준·지도상의 유의점·지도서 근거가 있습니다.

## 검증

모든 차시를 만든 사람과 다른 검토자가 지도서와 차시 하나씩 대조했습니다
(차시명 · 주요 학습 내용 · 용어 정의 · 정답 근거 · 지도상의 유의점).
고친 내용은 각 차시 「교사 안내」 맨 끝 「지도서 대조 검증」에 있습니다.

- 기사·영상: 본문에 넣지 않고 자료실에서 **링크**로만 연결했습니다.
