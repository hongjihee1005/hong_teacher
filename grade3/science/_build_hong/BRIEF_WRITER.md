## 설계 원칙 (선생님 요구)
1. **개념·답을 먼저 보여 주지 않습니다.** 순서: 궁금해하기/예상 → 탐구(실험·관찰·조사) → 결과 → 우리 반 결론(define) → 교과서 문장(한눈에 쏙)과 비교 → 적용 → 개념 확인(check) → 질문 판.
2. 실험·관찰이 있는 차시: pred → lab(교과서 순서대로 점검표 ≤7줄, 지도서 안전 유의점 ≤3줄, 실험관찰 같은 기록표, 교과서 버전 앱 가상 실험실 link) → pvr. 조사 차시는 cards(자료 번호) + csq(주장-근거-질문)로 근거를 대게 합니다.
3. 사고전략: S — see(보기-생각하기-궁금해하기), sort(예·아닌 예), define. O 개념 구축 — venn(같은 점·다른 점), csq. O 탐구 정리 — cards + csq + cse(연결-확장-도전). P 발표 — task/talk 발표·칭찬, iuti(예전 생각-지금 생각)로 단원 핵심 질문 돌아보기, check.
4. 교과서 탐구 활동, 한눈에 쏙, 형성 평가, 과정 중심 평가(지도서 원문과 쪽수)는 그대로 넣습니다. 채점은 교과서·지도서 사실만. 예상·느낌·경험·설계·의견은 채점하지 않습니다(talk/cols 또는 sort 항목 'k':'*').
5. 단원 지도상의 유의점을 지킵니다. 2·3단원: 생물학적 분류체계·'적응'이라는 말을 쓰지 않음, 동식물 이름·특징 암기·평가 금지, 생활용품은 생김새를 이용한 것 위주. 4단원: '완전 탈바꿈' 같은 지도서에 없는 말 금지, 포유류·조류 같은 계통 용어 금지, 번데기는 '움직이지 않는다' 대신 '이동하지 않는다'. 생명 존중(만지지 않기, 손 씻기, 자연으로 보내기)과 징그러운 사진 금지.
6. 학생 화면은 3학년 말투 '~해요'. 실제 학교 이름 금지. 지도서에만 있는 예시 답안(교과서 축소본 빈칸의 붉은 글씨)은 "지도서 N쪽"으로 적고 "『과학』 N쪽"이라고 쓰지 않습니다.
