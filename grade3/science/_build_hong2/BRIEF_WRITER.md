## 설계 원칙 (선생님 요구 + 3-1 버전 검토 결과)
1. **답·개념을 먼저 보여 주지 않습니다.** 순서: 궁금해하기 → (관찰) → 🧭 실험 설계(무엇을 해 볼지, 공정하게 비교하려면 무엇을 같게 할지, 무엇을 볼지·잴지) → 🔮 예상 표 → 🧪 실험 → 📊 우리 반 자료판 → ⚖️ 예상과 결과 비교 → ✍️ 근거로 결론(그다음 교과서 문장과 비교) → 개념 확인 → 생각+/질문.
2. **실험·관찰 차시는 위 흐름을 기본으로** 합니다. 결과가 표로 모이는 실험이면 `grids`를 정의해 pgrid·board·gcmp·claim이 같은 표를 쓰게 합니다. 숫자로 재는 실험(소리 측정기 숫자, 배지의 점 수 등)은 `type:'num'` 열로, 셋 이상으로 나누면 `opts`로.
3. **조사·표현·설계·캠페인 차시도 탐구로**: 질문 → 조사 계획(design으로 '무엇을 어디서 찾을까/무엇을 기준으로 고를까') → 자료 모으기(cards, 반 전체 조사는 board로 모둠별 결과 모으기) → 근거로 주장(csq 또는 claim + `evs`로 고정 근거) → 발표·평가. 낱말 카드로 교과서 문장을 조립하는 `define`은 쓰지 마세요(결론은 claim).
4. **여러 날 걸리는 실험**(예: 배지 배양 3일)은 그 차시 안에서 결과까지 꾸며 내지 말고, 단계 이름·ask·note에 "오늘 준비 → ○일 뒤 관찰" 흐름을 분명히 쓰고 자료판은 관찰하는 날 채우게 합니다. 가상 실험실(교과서 버전 앱) 단추로 미리 보는 것은 '참고'로만.
5. 교과서 탐구 활동·한눈에 쏙(문장·정답)·형성 평가·차시 평가 기준(지도서 원문과 쪽수)은 그대로 넣습니다. 채점은 교과서·지도서 사실만. 예상·느낌·설계·의견은 채점하지 않습니다(design에서 판정이 애매하면 `ok: None`).
6. **단원 지도상의 유의점과 이미 정한 것**(교과서 버전 검증에서 확정):
   - 1단원: 한 물질이 여러 상태로 있는 것(물·얼음·수증기)은 다루지 않음. 질량·밀도·무게·부피 같은 크기 성질 X. 입자 배열 X.
   - 2단원: 대기 성분·층상 구조 X, 침식·운반·퇴적 X, 밀물·썰물은 바닷물 높이 변화만(‘조석’ 용어와 원인 X). 갯벌은 진흙만이 아님(모래·펄). 추암 촛대바위는 강원 동해.
   - 3단원: 소리 전달의 과학적 원리(파동 등) X, 단위 dB·Hz X(숫자만), 너무 큰 소리·귀 가까이 X, 소리 자체를 나쁘게 보지 않기. 다른 책상에서 두드린 소리는 '거의 들리지 않음(0번)'.
   - 4단원: 병원체 종류·감염병 특성·면역 X, 세균·바이러스는 일상 수준(앱은 '병원체'), 감염 과정은 접촉·비말·공기·물·침 5가지로 한정, 이름·증상 암기 X, 지나친 두려움 X(“함께 노력하면 안전”), 형광 로션은 병원체가 아님, 손 씻기 6단계는 질병관리청 순서(손바닥·손등·깍지·손가락 마주 잡기·엄지·손톱 밑), 배지는 표면 검사 키트 면봉으로 손을 문지른 액체를 떨어뜨림. 4단원 『실험관찰』 쪽수는 54~65쪽.
7. **'공정하게 비교하려면 무엇을 같게 할까'**는 지도서가 실제로 같게 하라고 한 것만 `ok: True`로(예: 같은 크기·모양 막대, 같은 힘·같은 횟수). 안전 때문에 하는 일은 `ok: None` + 까닭에 '안전'을 씁니다. '변인 통제·조건 통제' 같은 말은 쓰지 않습니다.
8. 학생 화면은 3학년 말투 '~해요'. 실제 학교 이름 금지. 지도서에만 있는 예시 답은 "지도서 N쪽"으로 적고 『과학』 N쪽이라고 쓰지 않습니다. 학생에게 보이는 설계 까닭(w) 끝의 "(…쪽)"은 화면에서 자동으로 지워지니 넣어도 됩니다.
9. 확인(check) 문항은 정답이 하나로 분명해야 합니다(견본 검토에서 '투명한 플라스틱'처럼 오답 보기가 사실 맞는 경우가 나왔음).

## 견본 검토에서 나온 실수 — 다시 하지 마세요
- 교과서 순서와 다르게 관찰을 예상 뒤로 보냄 → 교과서 탐구 순서를 지킴.
- 근거 단추가 무엇을 본 결과인지 빠짐 → 열마다 `ev`(예: '글씨가', '사포에', '물에')를 넣음.
- 사진 이름에 재료가 들어가 답이 보임('유리 어항') → 물체 이름만.
- 교사 안내 쪽수 인용이 실제 쪽과 다름 → 꼬리말로 쪽을 확인.
- 3-1 검토: 기록표 흐린 글(placeholder)에 결과를 씀, 예상 단계 tip에 결론을 흘림, 조사 안내문에 결론이 될 분류를 먼저 적음, 정답 숫자를 자료 카드로 줌, 그림 문자만 있는 카드(실제 사진·간단한 SVG 그림을 쓰세요).
