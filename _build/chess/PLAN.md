# 체스 학습관 계획 (`special/chess/`, 2026-10-11 시작 · 첫 화면 '특색교육' 묶음)

선생님과 정한 것(2026-10-11 대화):
- 학년 구분 없이 **모든 학생이 1마당 1차시부터 끝까지** 차례대로. 차시를 아주 잘게 나누고 설명은 자세히, 예시는 여러 번.
- 용어는 원래 이름 그대로(킹·퀸·룩·비숍·나이트·폰, 체크·체크메이트·캐슬링·프로모션·앙파상 …).
- 혼자 익히는 자료. 차시 짜임: 📖 설명(3~6장) → 👀 예시(3~5개, 움직이는 보기) → 👆 따라 하기(2~3번) → ✏️ 연습(8~12문제, 할 때마다 새 문제) → ⭐ 마무리.
- 틀리면: 처음엔 실마리 + 왜 틀렸는지 판 위에 보여 주기, 두 번째엔 바른 답을 보여 주고 비슷한 문제 하나 더.
- **저절로 나오는 힌트**(아무 움직임이 없을 때, 화면을 건드리면 처음부터 다시 셈):
  | 문제 종류 | 1번째 | 2번째 | 3번째(답) |
  |---|---|---|---|
  | 쉬운 조작(easy) | 10초 | +10초 | +10초 |
  | 한 수 생각(one) | 15초 | +15초 | +15초 |
  | 깊은 생각(deep) | 20초 | +20초 | +20초 |
  읽어 주기가 켜져 있으면 읽기가 끝난 뒤부터, 꺼져 있으면 문제가 나온 뒤 '읽을 시간'(글자 수 ÷ 5초, 최소 3초 — 어림값)이 지나고부터 셈.
  선생님 설정: 빠르게(×0.5) · 보통 · 느긋하게(×2) · 끄기. 💡 힌트 단추는 언제나. 확인 시험·인공지능 대결에서는 저절로 나오지 않음.
- 🔊 읽어 주기(브라우저 한국어 음성, 켜고 끄기).
- 더한 아이디어: 진도 지도·등급(마당을 마치면 폰 → 나이트 → 비숍 → 룩 → 퀸 → 킹), 🔁 다시 보기(배운 차시에서 3문제), 마당 수료증 인쇄, (4마당부터) 대국 뒤 돌아보기.
- **교재 한글 파일(`special/chess/book/*.hwpx`)은 2026-10-11부터 선생님이 직접 고칩니다.** `gen_book.py`로 다시 만들어 덮어쓰지 마세요(고친 내용이 사라짐). 새 마당 교재는 새 파일로만 만들고, 사이트에는 선생님이 말할 때만 올립니다.
- 진도는 그 기기 localStorage(`hj-chess-v1`)에만. 반 전체 진도 보기는 서버가 없어 못 함.
- 작게 만들어 써 보고 고치기: ① 공통 틀 + 규칙 엔진 → ② 1마당 공개 → ③ 선생님·아이들이 써 보고 고칠 점 → ④ 2마당부터 차례로(인공지능 대결은 4마당 즈음).
