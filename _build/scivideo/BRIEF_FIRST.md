# 「처음 배우는 과학」 — 처음 익히는 개념 영상 만들기 안내 (2026-11-26 선생님 요청)

학교에서 **처음 배울 때** 쓰는 영상. 「과학 원리 돋보기」(복습·요약에 가까움, `s*`)와 따로, 폴더 `f{학년}ep{화}`(화 번호는 원리 돋보기와 같은 차시 번호, 예: `f3ep05` = 3-1-2-a 「동물을 어떻게 분류할까?」), 장면 클래스 `F3Ep05`.
캔바 AI로 만든 **실제와 가까운 그림(사진풍)** 을 넣어 처음 보는 대상의 실제 모습을 보여 줌.

## 짜임 (한 편 5~6분, 넘치면 두 편으로 나눔 — 이름 f3ep05a·f3ep05b는 쓰지 말고 먼저 보고)
1. `opening()` (SERIES = "처음 배우는 과학")
2. **궁금해요** — 실제 그림 한 장으로 질문을 던짐(앱 도입)
3. **새 낱말** — 처음 나오는 낱말을 실제 그림 위 이름표·화살표로 짚으며 소개(예: 더듬이, 지느러미)
4. **탐구** — 앱의 실험·관찰 과정을 차례대로. 결과 전에 반드시 `pause_screen`으로 예상하기
5. **개념 설명** — 실제 그림 위에 화살표·동그라미로 짚으며 천천히. 그림 하나에 핵심 하나
6. **확인해요** — 질문 → `pause_screen` → 답(앱 형성 평가에서)
7. **생활 속** — 실제 그림(앱에 있는 예만)
8. `closing(핵심 한 줄, next_preview="처음 배우는 과학 3학년 6화 · …")`
- 말은 더 느리고 쉽게, 새 낱말은 두 번 말하기. 자막은 한 줄 30자 안팎. 내용은 **그 차시 앱에 있는 것만**(앱 원본·apptext.py, `BRIEF_MAKER.md`의 '지킬 것' 그대로).

## 실제 그림 (캔바)
- 그림 파일은 `photos/<편>/<이름>.jpg` (1920×1080, JPG 품질 85). 장면에서는 `firstkit.photo('f3ep05/snail', width=…)`처럼 씀(둥근 테두리 액자). `firstkit`이 없으면 만들 것: ImageMobject + 둥근 테두리, 그림 위 이름표(화살표 먼저, 이름표는 위에), 동그라미 강조.
- 만드는 차례 (캔바 MCP 도구):
  1. `generate-image` — 그림마다 한 번. prompt는 한국어로 '초등 과학 영상에 쓸, ○○을 실제 사진처럼, 무엇이 잘 보이게, 밝고 깨끗한 배경, 글자 없음', aspectRatio `LANDSCAPE_16_9`. `get-generate-image-job`으로 SUCCESS까지(사이 15초쯤 기다림). 결과의 MEDIA id를 적어 둠.
  2. 여러 장을 모아 `create-design` 한 번: references에 MEDIA id들(최대 10), brief '사진 한 장씩 각 쪽을 가득 채운 디자인, 글자·장식 없이', format 'YouTube Thumbnail'. `get-create-design-async-job`으로 완료까지.
  3. `get-export-formats` 확인 뒤 `export-design` png width 1920 → 받은 주소들을 `curl -sS -o`로 받기(쪽마다 하나, **빈 흰 쪽이 섞여 나올 수 있음** — 열어 보고 버림). 사진을 열어 어느 그림인지 확인해 이름을 붙이고 JPG로 바꿈.
- **캔바 AI 사용 한도가 있음**("Credit quota cooldown"이 뜨면 몇 분 기다렸다 다시). 한 편에 그림 5~8장만. 같은 그림을 두 번 만들지 않게 media id·파일을 꼭 적어 둠(`photos/<편>/README.md`: 이름 · prompt · media id).
- 그림 확인: 과학적으로 틀린 곳(다리 수, 날개, 더듬이, 지느러미 모양 등)이 있으면 쓰지 말고 다시 만들기. 사람 얼굴이 크게 나오는 그림은 피함. 글자가 들어간 그림은 쓰지 않음.

## 만들기
- 음성: `TTS_SPEED=1.0 ./make_voice.sh f3ep05` (음성 만들기 → 음성 길이에 맞춰 렌더링 → 음성 얹기 → `f3ep05/f3ep05_final_voice.mp4`). 저화질 미리보기는 `MEDIA=media_p ./render.sh f3ep05 preview`.
- 장면 사진 `media/frames/<편>/sheet*.png`를 모두 열어 확인(겹침·잘림·자막 띠·이름표·로고, 그림 위 글자가 읽히는지).
- 공통 파일(`series_style.py` 등)은 고치지 않음. 커밋·푸시는 정리하는 쪽이 함.
