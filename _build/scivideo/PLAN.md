## 정한 것
- **두 시리즈:** 🔍 「과학 원리 돋보기」(개념 설명, 편마다 1~2분) · 🧠 「과학 마인드맵」(단원 정리, 편마다 1.5~2분). 목록 `EPISODES.md`(사람이 읽는 표) → `episodes.py`(화 코드·폴더·차시 앱·제목, 메뉴 만들 때 씀).
- **이름:** 개념 `s3ep01`(3학년 1화, 장면 클래스 `S3Ep01`), 마인드맵 `s3mm01`(3학년 마인드맵 1, `S3Mm01`). 학년마다 1부터, 학년 안에서 1학기 → 2학기, 단원 차례.
  앱이 없던 단원(4-2 1단원·6-2 3단원)을 나중에 더할 때는 번호를 다시 매기지 말고 그 학년 마지막 번호 뒤에 이어 붙임(이미 만든 영상 이름이 바뀌지 않게).
- **차례:** 3-1 → 3-2 → 4-1 → 4-2 → 5-1 → 5-2 → 6-1 → 6-2. 단원마다 개념 편을 모두 만든 뒤 그 단원 마인드맵.
- **바탕:** 그 차시 교과서 버전 앱(`gradeN/science/semS/uU-L.html`, 4~6학년은 원본 `_build_tb/src[2]/`)의 학습 목표·실험·'한눈에 쏙' 정리·형성 평가. 앱에 없는 내용은 넣지 않음. 지도서 글을 영상에 옮겨 쓰지 않음.
- **색·꾸밈(선생님 요청 2026-10-25 "과학은 수학과 다른 색으로, 학년별로도 다른 식으로"):** `sci_theme.py`. 수학은 단색 바탕만 학년·학기별로 다르지만, 과학은 학년마다 공책 모양이 다름 —
  3학년 「관찰 공책」(연두 + 모눈, 둥근 이름표, 돋보기, 마인드맵 가운데 원·굽은 가지) · 4학년 「탐구 노트」(청록 + 공책 줄·빨간 여백선, 꼬리표, 플라스크, 둥근 네모·굽은 가지) ·
  5학년 「실험 기록장」(모래빛 + 점 격자, 왼쪽 색띠 네모, 원자, 육각형·꺾은 가지) · 6학년 「연구 설계도」(청사진 + 큰·작은 모눈, 이중 테, 행성, 고리 달린 행성·곧은 가지). 2학기는 바탕 빛깔만 조금 다름.
  오프닝에 '3학년 · 관찰 공책'처럼 꾸밈 이름이 나오고, 이름표·자막 띠·멈춤 화면·마무리 테두리가 그 학년 색. 내용 그림의 색(빨강 힘·초록 답 등)은 모든 학년 같음.
- **음악(선생님 요청 2026-10-25 "음악도 과목별로 약간 다르게, 분위기는 똑같이"):** `music/gen_bgm.py --style piano --subject science` — 수학과 같은 빠르기·쿵짝 반주·끊어 치는 가락에, 조를 사장조로 옮기고 가락 위에 글로켄슈필(맑은 종소리)을 한 옥타브 위로 작게 겹침. 곡마다 seed는 폴더 이름에서(편마다 다른 가락).

## 한 편 만드는 차례
1. `episodes.py`·`EPISODES.md`에서 그 편의 차시 앱·핵심 장면을 보고, 앱 HTML의 글을 읽는다(실험 순서·결과·정리 문장·오개념).
2. `sNepMM/scene.py`를 쓴다(앞 편을 본뜨고 공통 부품 `series_style.py`·`scikit.py`·`mindmap.py`).
3. `./make_final.sh sNepMM` → 장면 사진 모두 확인 → 고칠 것이 있으면 다시.
4. 커밋·푸시, 아래 표에 ✅.
