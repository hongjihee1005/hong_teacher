# 생각 도구 (thinking-tools)

주소: https://hongjihee1005.github.io/thinking-tools/

초등교사 홍지희가 만든 어린이 생각 도구입니다. 하버드 대학교 Project Zero의 사고 루틴 23가지를 탐구 단계별·과목별로, 학생용 안내와 활동지로 담았습니다.

**이 저장소의 파일은 직접 고치지 마세요.** 원본은 `hongjihee1005/hong_teacher`의 `_build/strategy/`(`kids.py`)이고, `.github/workflows/sync.yml`(원본에서 가져오기)이 한 시간마다 `_build/strategy/standalone/`을 가져와 맞춥니다.
