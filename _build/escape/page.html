선생님 안내
이 방의 수학{MATH}
  • 방 그림 속 물건을 누르면 크게 보여요. 단서는 수첩에, 상자·서랍에서 찾은 물건은 가방에 저절로 모여요. 크게 본 그림 속 작은 쪽지·서랍도 눌러 볼 수 있어요.
  • 가방에서 물건을 고른 뒤 쓸 곳을 누르고, 가방의 두 물건을 차례로 누르면 합쳐져요.
  • 자물쇠는 숫자·방향·색깔·모양 네 가지예요. 여러 곳의 단서를 이어야 열려요.
  • 막히면 어디를 볼까?와 자물쇠마다 있는 힌트 보기를 써요. 힌트와 틀린 횟수가 적을수록 별이 많아요. 정답 보기는 자물쇠마다 처음 볼 때 힌트 3번으로 세어요.
  • 걸리는 시간은 1학년 방 30분, 2학년 25분, 3학년부터 20분쯤이에요(이 자료의 어림값). 시작 화면에서 시간 제한을 바꿀 수 있어요.
  • 하던 중에 새로 고치거나 다른 쪽에 다녀와도 같은 탭이면 시작 화면에서 이어서 하기를 할 수 있어요(떠나 있던 동안은 시간이 멈춰요).
  • 모둠 대항: 시작 화면의 '이름 또는 모둠' 칸에 모둠 이름을 적고, 선생님은 점수판을 띄워 다 같이 출발해요. 탈출 화면의 결과 코드를 넣으면 순위가 나와요.
  • 개별 활동: 이름이나 번호를 적고 풀어요. 탈출 화면을 캡쳐해 내고, 결과 코드를 점수판에 넣어 확인해요.
  • 탈출한 뒤 수첩을 보며 어떤 단서를 어떻게 이었는지 말해 보아요.
