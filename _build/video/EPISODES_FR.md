# 「수학 원리 돋보기」 분수 특별편 — 분수 기초 차근차근 (11편)

선생님 요청(2026-11-23): 아이들이 **진분수·가분수·대분수**를 잘 모르고, **부분을 분수로 나타내기**를 잘 못함 → 단계별로 차근차근 설명하는 영상, 여러 편으로.
3학년 본편(47~49화 분수와 소수, 12~14화 진분수·가분수·대분수)보다 **한 단계씩 더 잘게** 나누어 보여 주고, 아이들이 자주 하는 실수를 영상 안에서 직접 짚습니다.

- 폴더 `gfep01` … `gfep11`, 장면 클래스 `GfEp01`, 화면 이름 "분수 특별편 1화", 바탕색 연청록(`THEMES[("F", 1)]`).
- 명령: `GRADE=f ./make_final.sh 1` (최종본 + 피아노 배경음악 + 장면 사진 `media/frames/gfep01/`).
- 낱말은 교과서 낱말(분모·분자, 진분수·가분수·대분수, 'ㅁ분의 ㅇ', '1과 4분의 3')을 씀. 3학년 1학기 6단원·2학기 4단원 범위, 마지막 2편은 4학년 분수 계산의 바탕.

| 화 | 영상 제목(질문) | 대표 예시 | 단계·핵심 장면 | 자주 하는 실수(영상에서 짚음) |
|---|---|---|---|---|
| 1 | 분수는 '똑같이' 나누는 데서 시작해요 | 케이크 4조각(같음/다름), 고르기 4문제 | 겹쳐 보기 → 크기가 다르면 분수로 못 씀 → 똑같이 나눈 것 고르기 | 조각 수만 세고 크기를 안 봄 |

| 3 | 헷갈리는 그림도 3단계로 | 흩어진 칸 3/6, 안 칠한 부분, 2칸 칠·3칸 안 칠 → 2/5(2/3 아님) | 흩어져도 세면 됨 → 색칠하지 않은 부분 → 분모는 '전체' 칸 수 | 분모에 '안 칠한 칸 수'를 씀 |
| 4 | 칸 크기가 다르면 어떻게 할까? | 큰 칸 1 + 작은 칸 2 → 선을 그어 4칸 → 1/4 | 칸 크기 확인 → 선을 더 그어 똑같이 → 3단계로 | 크기가 다른 칸을 그대로 셈(1/3) |
| 5 | 분수만큼 색칠하기 | 3/4, 2/5, 5/8 | 분모만큼 똑같이 나누기 → 분자만큼 칠하기 → 다시 읽어 확인 | 분자만큼 나누기 |
| 6 | 여러 개 중의 부분도 분수로 | 사과 12개를 3개씩 4묶음 → 9는 12의 3/4, 2개씩이면 4는 12의 2/6, 연습 6은 8의 3/4 | ① 몇 묶음으로 똑같이? → 분모 ② 그중 몇 묶음? → 분자 ③ '9는 12의 4분의 3' | 분자에 개수(9)를 씀(4분의 9) |
| 7 | 몇 개가 모이면 1이 될까? | 1/5이 5개 = 5/5 = 1, 3/3·8/8·6/6 = 1, 연습 1/6이 6개 | 단위분수 한 조각씩 모으기 → 분자와 분모가 같으면 1 | 5/5를 5로 생각 |
