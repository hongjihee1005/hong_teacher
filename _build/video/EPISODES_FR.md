# 「수학 원리 돋보기」 분수 특별편 — 분수 기초 차근차근 (11편)

선생님 요청(2026-11-23): 아이들이 **진분수·가분수·대분수**를 잘 모르고, **부분을 분수로 나타내기**를 잘 못함 → 단계별로 차근차근 설명하는 영상, 여러 편으로.
3학년 본편(47~49화 분수와 소수, 12~14화 진분수·가분수·대분수)보다 **한 단계씩 더 잘게** 나누어 보여 주고, 아이들이 자주 하는 실수를 영상 안에서 직접 짚습니다.

- 폴더 `gfep01` … `gfep11`, 장면 클래스 `GfEp01`, 화면 이름 "분수 특별편 1화", 바탕색 연청록(`THEMES[("F", 1)]`).
- 명령: `GRADE=f ./make_final.sh 1` (최종본 + 피아노 배경음악 + 장면 사진 `media/frames/gfep01/`).
- 낱말은 교과서 낱말(분모·분자, 진분수·가분수·대분수, 'ㅁ분의 ㅇ', '1과 4분의 3')을 씀. 3학년 1학기 6단원·2학기 4단원 범위, 마지막 2편은 4학년 분수 계산의 바탕.
