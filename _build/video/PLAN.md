# 「수학 원리 돋보기」 제작 진행표 (이어 하기용)

**새 세션이면 이 파일부터 읽고, 아래 '다음 할 일'부터 이어서 만드세요.** (선생님 요청 2026-10-13: 미리보기 없이 최종본을 만들고 다음 편으로 계속, 이 작업은 자동 승인)

## 한 편 만드는 차례
1. `EPISODES.md`·노션 '영상 목록'에서 그 편의 차시·예시·핵심 장면을 보고, 수학방 앱(`grade3/math/sem2/u?-*.html`)에서 같은 차시의 `question`·`summary`·예시 수를 확인한다.
2. `epNN/scene.py`를 쓴다(앞 화를 본뜨고, 공통 부품 `series_style.py`·`base10.py`·`division.py`를 씀. 새 부품은 공통 파일에 함수로).
3. `./make_final.sh NN` — 최종 렌더링(1920×1080·30fps) → 그 길이의 피아노 배경음악 → `epNN_final_bgm_piano.mp4` → 장면 사진 모음(`media/frames/epNN/`).
4. 장면 사진을 **모두 보고** 숫자·계산·겹침을 확인한다. 고칠 것이 있으면 고쳐 다시 3.
5. 커밋·푸시(작업 브랜치 `claude/stoic-allen-97qqrm`), 노션 '영상 목록' 그 편 상태를 '완성'으로(화 칸에 'N화 (코드)'), 아래 표에 ✅.
6. 다음 편으로.

## 정한 것
- 화 번호는 만든 차례대로(1화, 2화, …). 마무리 '다음 화 예고'에는 다음 편 제목을 넣는다.
- 영상 파일은 **배경음악 넣은 최종본만** 저장소에 올린다(소리 없는 최종본·미리보기는 `.gitignore`, 필요하면 원본으로 다시 만듦). 1화만 예외로 둘 다 있음.
- 배경음악: `music/gen_bgm.py <초> --style piano`(직접 지은 곡 + FluidR3 피아노 음원, MIT), 크기 -34 LUFS.
- 제작 도구가 깨지면(Bus error 등) `/opt/manimenv`를 새로 만든다: `python3 -m venv /opt/manimenv && /opt/manimenv/bin/pip install manim mido fonttools` (+ apt: libpango1.0-dev fonts-noto-cjk fluidsynth fluid-soundfont-gm). README '설치' 참고.
