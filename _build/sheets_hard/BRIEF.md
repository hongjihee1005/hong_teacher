# 수학 활동지 도전형 다시 쓰기 (2026-10-30 선생님 요청)

## 무엇이 문제였나
3~6학년 수학 활동지 기본형·도전형 96쌍을 견주니, 기본형 글의 72~93%가 도전형에 그대로 있었습니다.
짜임이 '도전형 = 기본형 문제 그대로 + ③말해 보기는 직접 쓰기 + ⑥도전하기 한 칸'이라 ①②④⑤(그리고 그 밖의 칸) 문제가 똑같았습니다.
선생님이 고른 방향: **도전형의 ①~⑤(⑥ 앞의 모든 칸)를 새 문제로 다시 쓰기.**

## 규칙
1. **기본형은 한 글자도 바뀌면 안 됩니다.** 다 만든 뒤 `python3 _build/sheets_hard/basic_same.py <경로 글자>`로 확인하세요(스크립트를 다시 돌리면 content.hpf 날짜만 바뀌는 것은 괜찮음).
2. 도전형의 각 차시·각 칸(만져 보기·그려 보기·떠올리기·확인하기 …)은 **칸 이름·활동 종류·차시 목표는 그대로**, 문제(수·상황·묻는 것)를 새로 씁니다.
   - 더 어렵게: 더 큰 수·받아올림/받아내림이 더 많은 수·여러 단계·거꾸로 묻기(□ 구하기)·까닭 쓰기·조건이 하나 더 붙은 문제·틀린 곳 찾기 등.
   - **그 학년·그 단원에서 배운 내용 안에서만**(다음 학년·다음 단원 내용 금지). 지도서·교과서 차시 목표(차시 머리의 '탐구 질문'·목표)와 이어지게.
   - 기본형과 같은 수·같은 상황 문장을 그대로 쓰지 마세요(이야기 장면 소개 글(scene)·탐구 질문·칸 제목은 그대로 둬도 됨).
   - 이미 도전형에만 있는 ③(직접 쓰기)·⑥도전하기는 그대로 두되, 새로 쓴 ①~⑤와 겹치면 ⑥은 손대지 말고 ①~⑤ 쪽을 바꾸세요.
   - 그림(SVG)이 문제의 수를 보여 주는 칸은 그림도 새 수에 맞추거나(같은 그림 함수에 새 값), 그림이 필요 없는 문제로 바꾸세요. 그림과 글의 수가 어긋나면 안 됩니다.
3. **정답(교사용 정답 줄·w.key)도 반드시 새 문제에 맞게.** 4~6학년은 답을 될 수 있는 대로 코드로 계산하세요(지금 스크립트처럼). 손으로 쓴 답은 두 번 검산.
4. 어린이 말투·맞춤법·띄어쓰기는 지금 활동지와 같게. 조사는 받침에 맞게('이(가)' 금지 — 새로 쓰는 곳에서).
5. 한 장에 들어가는 분량을 크게 늘리지 마세요(칸 수·줄 수 비슷하게).

## 4~6학년 (`gradeN/math/_build/sheets/gen_<slug>.py`)
- 스크립트 안의 `if w.basic: … else: …` 갈래로 도전형을 나눕니다. 지금 공통인 줄(`w.ask`·`w.table`·`w.fill`·`w.choices`·`w.pic`·`w.key` 등)을
  `if w.basic:` 쪽에 그대로 옮기고 `else:` 쪽에 새 문제를 씁니다(기본형 출력이 바뀌지 않게 — 줄 순서·글 그대로).
- 한 스크립트에 교과서 버전(`tbN`)과 이야기 버전(`stN`) 함수가 함께 있습니다. **둘 다** 고치세요(이야기 버전은 장면·인물 이름이 다르니 거기에 맞게).
- 만들기: `cd gradeN/math/_build/sheets && python3 gen_<slug>.py` (스크립트가 `check`도 돌림). 오류 없이 4개 파일이 다시 만들어져야 합니다.
- Python 3.11에서도 돌아가야 합니다(f-string 안에 같은 따옴표 겹쳐 쓰기 금지). `python3.11 -m py_compile`이 있으면 확인.

## 3학년 (`grade3/math/{sem1,sem2,sem1-soop,sem2-soop}/sheets/*_도전형.hwpx`, 생성 스크립트 없음)
- 도구: `python3 _build/sheets_hard/hwpx_sub.py dump 파일.hwpx`로 글 조각 번호를 보고,
  바꿀 목록 `[[번호, "옛 글", "새 글"], …]`을 **`_build/sheets_hard/g3/<학기폴더>__<파일이름>.json`** 에 저장한 뒤
  `python3 _build/sheets_hard/hwpx_sub.py apply 파일.hwpx 그.json`. (옛 글이 다르면 멈추므로, 원본 파일에 한 번만 적용 — 다시 적용하려면 `git checkout`으로 원본을 되돌린 뒤.)
- 글 조각 하나를 통째로 바꾸며 표·칸 모양은 그대로입니다. 새 글은 옛 글과 비슷한 길이로(칸 폭 고정). 표 안 수 칸도 조각마다 바꿀 수 있습니다.
- 맨 끝 '【교사용】 … 정답 (도전형)' 아래 차시별 정답 줄도 새 문제에 맞게 바꾸세요.
- 그림(이미지)은 바꿀 수 없으니, 그림이 수를 보여 주는 칸은 그림과 어긋나지 않는 문제(그림을 쓰되 다른 것을 묻기, 또는 그림과 상관없는 글 문제)로 쓰세요.
