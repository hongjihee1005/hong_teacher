# 초등교사 홍지희

2022 개정 교육과정 교과서·지도서를 바탕으로 만든 초등 1~6학년 수업·학습 자료실입니다.

- `index.html` : 첫 화면 (1~6학년 고르기)
- `gradeN/index.html` : N학년 → 국어·수학·사회·과학 방 고르기
- `gradeN/과목/index.html` : 과목 → 1학기·2학기 고르기 (`korean`, `math`, `social`, `science`)
- `gradeN/과목/semN.html` : 아직 자료가 없는 학기의 '준비 중' 화면

3학년 2학기 자료(아래 세 폴더)는 주소를 그대로 두고 `grade3/…`에서 연결합니다.

- `science/` : 과학방 — 1~4단원 탐구 앱 25개 (`u단원-번호.html`)
- `social/` : 사회방 — `*-class.html` 수업용, `*-home.html` 개별 학습용
- `math/` : 수학방

예전 사회 자료 주소(맨 위 폴더의 `u1-…html`, `u2-…html`)로 들어오면 사회방의 같은 자료로 자동 이동합니다.
파일은 각각 따로 열어도 작동하며, 인터넷이 없어도 실행됩니다(글꼴 제외).
